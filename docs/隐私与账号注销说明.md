# 拾光集市隐私与账号注销说明（校内试运行稿）

本说明描述当前代码实际处理的数据。校内试运行开始前，运营负责人应核对真实联系人、保存期限和学校要求，并将经确认的用户版本公布；本文不代替法律审查，也不承诺尚未配置的响应时限。

## 数据与用途

| 类别 | 当前收集或生成 | 用途和访问边界 |
| --- | --- | --- |
| 账号 | 登录邮箱、昵称、密码哈希、同意版本、会话时间与设备信息 | 登录、找回与会话管理；密码原文不保存。超级管理员 `guo` 无登录邮箱。 |
| 校园认证 | 校园邮箱、校区、验证码状态；申诉时用户主动上传的材料 | 确认校内资格和人工申诉；材料由私有文件接口按权限读取，不作为公开资料。 |
| 交易与沟通 | 商品描述/图片、收藏、聊天、线下订单、评价 | 展示商品、沟通和完成线下交付；聊天正文和未公开商品不进入公共搜索或缓存。 |
| 治理与审计 | 举报理由、证据、审核动作、后台审计记录及导出 | 处理纠纷和追溯后台操作；导出需再校验角色、创建人、期限和撤销状态。 |
| 技术日志 | 请求 ID、路径、方法、状态与耗时 | 排障与滥用分析；不记录请求正文、查询串、Cookie、Authorization 或验证码。 |

用户上传的校园材料、举报证据和私聊内容可能包含敏感信息，提交前应提示用户只提供必要内容。前端对用户文本使用文本渲染，不把其作为 HTML 执行。公开页面可能显示昵称、商品、评价与成交状态；不要把它们视为匿名数据。

## 保存与清理

验证码和一次性 WebSocket 票据在 Redis 中短期到期；Redis 丢失后重新申请即可。登录会话、商品、订单、举报、审核及审计以 PostgreSQL 为准。会话过期或撤销满 30 天后，常驻 worker 清空其中的 IP 地址和设备信息。审计导出文件一小时过期，由常驻 worker 清理。校园申诉材料的配置保留期当前为 180 天；常驻 worker 每轮清理到期文件，并将材料键、文件名和申诉原因去标识。待审申诉保留待审状态，由审核人员继续处理；材料已到期时需依据剩余证据联系用户补充，不能将材料清理当成驳回决定。每类清理每轮最多处理 50 条，积压需监控并重复运行。备份可能在独立保留窗口内继续包含已在主库删除的数据，实际窗口须在试运行前由负责人确认。

## 账号注销流程

用户在“账户与安全”页可提交注销，需近期重新登录并输入确认短语。存在未完成订单、待处理举报或校园申诉时返回冲突，需先处理事项；后台人员必须先移交管理职责。成功后数据库事务撤销所有会话、清除登录邮箱和设备信息、改为内部墓碑用户名、下架商品、使校园认证失效，并让申诉材料立即到期。常驻 worker 随后移除私有申诉文件和该账号商品图片；在清理作业完成前，文件仍可能短暂留在磁盘，但接口不可再访问。已完成订单、评价和治理记录仍保留去标识的关联，不向用户保证完整硬删除。若 worker 停止，需恢复 worker 并核查积压。

用户可在账号页查看和修改昵称、管理设备会话。需要更正历史治理记录或咨询数据导出时，由运营人员核验身份并按后台权限处理。正式联系方式和处理时限尚待试运行组织者确认，不写入占位承诺。
