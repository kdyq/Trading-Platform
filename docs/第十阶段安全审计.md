## 独立复审和测试

`reviewer_deep` 独立复审发现并推动修复了卖家限流路径、账号注销缺口、私有材料清理、WebSocket 会话撤销、订单昵称快照、连接数量上限、待审申诉误驳回、会话设备信息无期限留存和后台读取缺少专用限流桶。复审后的全量检查记录：Ruff、mypy、后端 108 passed/15 skipped、隔离 PostgreSQL 迁移往返和集成门禁、前端类型检查/Lint/格式检查、48 项单测与生产构建均通过。跳过项为需隔离 PostgreSQL 环境的常规 pytest 入口，已由同次 PostgreSQL 门禁运行。

## 运行约束

限流按应用实例和 Redis 可用性工作，试运行入口仍需代理层容量限制。材料和图片清理依赖常驻 worker；停机时应在恢复后检查积压。隐私文本为试运行草稿，真实联系人、备份保留期及对外版本须在试运行前确认。
