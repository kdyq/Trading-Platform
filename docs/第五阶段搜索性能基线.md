# 第五阶段 PostgreSQL 搜索性能基线

代表性查询使用公开状态、分类、价格排序和稳定 ID 尾序：

```sql
EXPLAIN
SELECT id
FROM products
WHERE deleted_at IS NULL
  AND status IN ('on_sale', 'reserved', 'sold')
  AND category_id = :category
ORDER BY price, id
LIMIT 12;
```

迁移为公开商品新增部分索引：`ix_products_public_newest`、`ix_products_public_category_price` 与 `ix_products_public_campus_price`；收藏列表使用 `ix_favorites_user_created`，唯一约束 `uq_favorites_user_product` 保证幂等并发写入。

自动化 PostgreSQL 集成测试会在隔离 schema 中执行代表性 `EXPLAIN`、关键词/筛选查询、两次相同收藏、收藏列表和删除。测试数据量很小时 PostgreSQL 可能合理选择顺序扫描，因此基线只强制查询可解释、单条列表 SQL 和索引存在，不把特定计划节点写死。试运行数据增长后应使用 `EXPLAIN (ANALYZE, BUFFERS)` 复核实际行数与缓冲区命中，再决定是否启用 `pg_trgm`；本阶段不引入 Elasticsearch。
