# 「拾光集市」校园二手交易平台 · 前端设计文档

> 配套原型：`index.html`（本目录下，可直接双击打开体验）。
> 本文档只记录**设计本身**：设计定位、视觉系统、组件规范、页面布局、动效规范、验收基线。不含技术实现与后端内容。

---

## 1. 设计定位

| 项 | 结论 |
|---|---|
| 产品 | 面向校内学生的二手商品交易平台（网站） |
| 受众 | 在校大学生，既是买家也是卖家 |
| 一句话气质 | 像逛周末创意集市一样逛校园二手 |
| 设计关键词 | 暖调纸感 × 汽水橙 × 圆润卡片 × 市集烟火气 |
| 硬约束 | 明亮浅色单主题；**无暗黑主题、无蓝紫渐变**；全站唯一主色 |
| 情感目标 | 热闹但不杂乱、有人情味、交易可信 |

核心叙事：闲置好物「换个主人继续发光」。所有界面围绕这条叙事组织信息层级：**先让人逛起来，再让人放心买**。

## 2. 色彩系统

### 2.1 基础 Token

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#FFF6EA` | 全站页面底色（奶油纸感） |
| `--card` | `#FFFFFF` | 卡片 / 面板 |
| `--ink` | `#2B2118` | 主文字、选中态填充（暖墨棕，禁用纯黑 `#000`） |
| `--ink-2` | `#6B5D4F` | 次级文字、说明文字 |
| `--line` | `#F0E0CC` | 分割线、卡片描边、输入框描边 |
| `--primary` | `#FF6B35` | 汽水橙：主 CTA、价格、当前态、跑马灯底 |
| `--primary-deep` | `#E8531F` | 主色悬停 / 按压态 |
| `--sun` | `#FFC53D` | 芒果黄：手绘下划线、印章外的少量点缀 |
| `--leaf` | `#2E7D5B` | 认证与信任绿：认证徽章、信用分、印章 |
| `--leaf-soft` | `#E4F3EA` | 认证 / 信用元素的浅底 |

### 2.2 功能浅底（用于缩略图、色块分区）

| Token | 值 | 典型用途 |
|---|---|---|
| `--peach` | `#FFE3D2` | 教材、生活类缩略图底、悬停底 |
| `--lemon` | `#FFF1C9` | 数码键盘类缩略图底、跑马灯外浅底 |
| `--mint` | `#DDF2E4` | 运动户外、吉他类缩略图底 |
| `--rose` | `#FFE0DB` | 服饰、美妆类缩略图底 |
| `--sky-tint` | `#E3F0FA` | 平涂浅蓝（**非渐变**），平板 / 台灯类缩略图底 |

### 2.3 用色规则

1. **橙色只表达「行动与价格」**：CTA、价格数字、当前选中项。不用于普通正文强调。
2. **绿色只表达「信任」**：校园认证、信用分、审核通过。二者永不互相挪用。
3. 黄色只做装饰点缀（下划线、印章旁），不做按钮主色。
4. 每个区块同一主题、同一主色；全站不出现第二套品牌色。
5. 状态色：已售 = 内容 45% 透明 + 墨棕缎带；审核中 = 灰棕徽章（无红色警示，审核中是正常流程）。

## 3. 字体系统

| 用途 | 字体栈 | 备注 |
|---|---|---|
| 中文正文与标题 | `"PingFang SC", "Microsoft YaHei", "Noto Sans SC", "Source Han Sans SC", sans-serif` | 系统字体，零加载成本 |
| 价格与数字 | `"Bahnschrift", "DIN Alternate", "Segoe UI", Arial, sans-serif` | 统一加 `.num` 类，数字感强、表格对齐 |

字阶（桌面端）：

| 层级 | 字号 / 字重 | 用途 |
|---|---|---|
| H1 | `clamp(34px, 4.6vw, 58px)` / 900 | 首屏标题，2 行以内 |
| H2 | `clamp(24px, 3vw, 36px)` / 900 | 区块标题 |
| H3 | 17px / 800 | 卡片标题、信任项标题 |
| 正文 | 14–16px / 400–500 | 说明文字、列表 |
| 辅助 | 11–13px | 元信息（校区、卖家、徽章） |
| 价格 | 20–26px / 800（Bahnschrift） | 卡片价 22px、详情价 24px |

规则：标题不使用斜体与衬线；强调靠字重与颜色，不混入第二种字体。

## 4. 形状 · 阴影 · 描边

| 元素 | 圆角 | 说明 |
|---|---|---|
| 卡片 / 色块 | 16px | 全站统一 |
| 输入框 | 12px | 发布表单、搜索框内层 |
| 按钮 / 徽章 / chip | 全圆（999px） | 全部胶囊形 |
| 图片 | 12px（卡片内缩略区由卡片裁切） | — |

- 阴影统一**暖棕色调**：常态 `0 10px 30px rgba(190,120,60,.12)`，悬停 `0 18px 40px rgba(190,120,60,.20)`；禁止纯黑投影。
- 描边 1–1.5px `--line`；不用粗黑描边（那是其他风格的签名）。
- 无渐变按钮、无发光、无玻璃拟态；质感来自暖底 + 柔影 + 圆角。

## 5. 布局系统

- **容器**：`max-width 1180px`，左右 24px 内边距，居中。
- **垂直节奏**：区块间距 72–76px；区块标题与内容间 34–36px。
- **首屏（Hero）**：左右分栏（约 1.05 : 0.95），左文右卡；文字元素不超过 4 个（标题、副文、双 CTA）；装饰圆形与印章只做氛围。
- **栅格**：
  - 分类：4 列（≤900px 折为 2 列）
  - 商品：4 列（≤1024px 折为 2 列，≤560px 折为 1 列）
  - 信任区：2×2（≤768px 折为 1 列）
  - 数据带：4 列（≤768px 折为 2 列）
- **导航**：单行 68px，sticky 吸顶 + 毛玻璃；≤768px 收合为汉堡菜单（正式开发实现）。
- **核心界面画廊**：桌面端 pin + 横向巡览；移动端原生左右滑动。

## 6. 核心组件规范

### 6.1 按钮

| 类型 | 样式 | 交互 |
|---|---|---|
| 主按钮 `btn-primary` | 汽水橙底 + 白字 + 橙色投影 | 悬停：上浮 2px、加深为 `--primary-deep`、投影扩大；按压：`translateY(1px) scale(.98)` |
| 幽灵按钮 `btn-ghost` | 白底 + 描边 + 墨字 | 悬停：描边与文字变橙、上浮 2px |
| 图标按钮 | 38px 圆形 | 悬停浅橙底；带未读数角标（消息） |

规则：同一意图全站只用一个文案（如「发布闲置」）；CTA 文案桌面端必须单行；白字只允许出现在主色与墨棕之上。

### 6.2 商品卡（全站最重要组件）

结构自上而下：

1. **缩略区**（150px，功能浅底 + 商品主图，占位期用 emoji，正式版换实拍图）
   - 左上：状态徽章 —— 「校园认证 · 成色」（绿底）或「审核中 · 预计 2 小时」（灰棕底）
   - 右上：收藏计数 chip（`♡ 32`），点击变实心橙（`♥ 已收藏`）
2. **主体**
   - 价格（橙、Bahnschrift，可带划线原价）
   - 标题（最多 2 行截断）
   - 元信息行：`校区 东校区`、`卖家 计算机学院` + 右侧「信用 98」绿 chip
3. **操作条**（1px 上分割线，左右各半）
   - `♡ 收藏`：点击变 `♥ 已收藏`
   - `联系卖家`：橙色文字，直达私聊

**状态**：

| 状态 | 表现 |
|---|---|
| 默认 | 白卡、描边、常态阴影 |
| 悬停 | 上浮 6px、阴影加深、主图 `scale(1.12) rotate(-4deg)` |
| 已售 | 全卡内容 45% 透明 + 旋转缎带「已售」，操作禁用 |
| 审核中 | 徽章替换为「审核中」，操作区按钮显示「审核通过后开放」 |

### 6.3 分类 tile

白卡 + 图标色块（功能浅底 54px 圆角块）+ 名称 + 在售数量；悬停上浮 5px、右侧箭头滑入。八类：数码电子 / 教材书籍 / 生活家居 / 运动户外 / 服饰鞋包 / 乐器文创 / 美妆个护 / 求购专区。

### 6.4 筛选 chip

胶囊；默认白底描边灰字；选中墨棕填充白字；下拉型 chip 带 `▾`。组合：类目 chips + 右侧「校区 / 排序」下拉 chips。

### 6.5 校园认证印章（品牌记忆点）

SVG 圆形印章：绿色外圆 + 奶油内圆 + 中心对勾；环形文字「校园认证学生 · CAMPUS VERIFIED」沿圆排布并**匀速旋转（26s/圈）**，中心对勾保持静止。出现在首屏左上角，正式版可复用为认证徽章动效。

### 6.6 数据带

白底上下描边，4 项统计（在售好物 / 已认证学生 / 累计成交 / 好评率），数字橙绿交替，进入视口时从 0 滚动到目标值（1.6s）。

### 6.7 跑马灯（全站唯一）

汽水橙底白字，播报「今日上新 / 收藏动态 / 审核时效」，匀速左移循环（24s），`aria-hidden`。

### 6.8 信任区 tile

2×2 四种功能浅底（叶绿 / 柠檬 / 蜜桃 / 薄荷），白色圆角图标容器 + 标题 + 一句话说明：校园认证 / 信用评分 / 订单保障 / 举报快速处理。

### 6.9 表单控件（发布页为代表）

- label 在输入框上方，11.5px 加粗灰棕；
- 输入框白底 1.5px 描边 12px 圆角；
- 成色 = 胶囊单选（选中墨棕填充）；
- 图片上传 = 九宫格，首格封面，空格虚线「＋」；
- 审核提示条 = 叶绿浅底 + 「✓ 提交后进入审核队列…」；
- 主按钮通栏。

## 7. 页面设计（全站 11 页）

原型「核心界面画廊」已给出 6 个关键界面的视觉；其余页面沿用同一套语言，布局如下：

| # | 页面 | 布局与要点 |
|---|---|---|
| 1 | **首页**（原型完整呈现） | 吸顶导航 → 分栏 Hero（标题 / 双 CTA / 悬浮商品卡 / 认证印章）→ 数据带 → 跑马灯 → 分类 4×2 → 最新上架（筛选 chips + 商品网格）→ 核心界面画廊 → 信任 2×2 → 设计速览 → 页脚 |
| 2 | **分类 / 列表页** | 顶部分类横条 + 筛选 chips（类目 / 校区 / 成色 / 价格区间 / 排序）+ 商品网格（复用 6.2）；空结果状态：插画位 + 「换个筛选试试」+ 清空按钮 |
| 3 | **商品详情** | 左图集（主图 + 缩略条）+ 右信息卡（价格 / 标签 / 校区 / 卖家 / 信用分）+ 底部操作条（收藏 / 联系卖家）+「举报该商品」文字链；已售商品操作置灰 |
| 4 | **发布闲置** | 单栏表单：图片九宫格（≤9 张，首图封面）→ 标题 → 分类 → 价格 → 成色 → 校区 → 描述 → 审核提示条 → 提交审核；未认证用户进入时引导先认证 |
| 5 | **私聊** | 左会话列表（商品小卡 + 最后一条消息 + 未读角标）+ 右聊天窗（顶部对方信息与在线态、顶部商品卡、气泡、输入条）；气泡：我 = 橙底白字，对方 = 白底描边 |
| 6 | **订单** | Tab（进行中 / 已完成 / 已取消）+ 订单卡（商品、对方、交易方式、状态徽章、金额、操作按钮「确认完成 / 互评」）；完成后引导双方互评 |
| 7 | **个人中心** | 顶部身份卡（头像 / 昵称 / 校园认证徽章）+ 信用分环形卡（98/100）+ 三格统计（在售 / 已售 / 收藏）+ 菜单列表（我的发布、买卖订单、收藏夹、信用评价、举报记录） |
| 8 | **校园认证** | 三步流程：上传证件 → 人工核验（约 2 小时）→ 解锁交易；页脚固定绿色提示「未认证仅可浏览」；认证通过后徽章点亮动画 |
| 9 | **注册 / 登录** | 居中窄卡：手机号 + 验证码（注册含学号绑定）；登录后未认证用户首跳认证页 |
| 10 | **举报** | 从商品 / 用户页唤起弹层：类型单选（描述失实 / 违禁品 / 冒充学生 / 其他）+ 描述框 + 凭证图上传；提交后 24 小时响应承诺 |
| 11 | **管理后台**（原型已呈现，浅色后台） | 左侧栏：数据概览 / 商品审核（角标数）/ 用户管理 / 举报处理 / 分类管理 / 权限设置；审核队列行 = 商品缩略 + 标题价格 + 提交人 + 时间 + 「通过 / 驳回」；权限设置 = 角色卡（超级管理员 / 内容审核员 / 数据分析员）+ 开关，按角色授权 |

## 8. 动效规范（GSAP 3 + ScrollTrigger）

### 8.1 动效清单

| 动效 | 参数 | 目的 |
|---|---|---|
| 首屏入场时间轴 | 导航 `y:-16` 0.5s → 标题行 `y:44` stagger 0.12 → 副文/CTA → 悬浮卡 `back.out(1.4)` → 印章 `back.out(1.8)` | 建立视觉次序 |
| 悬浮卡呼吸 | `y:-12`，2.2–3.0s，yoyo 无限循环，`sine.inOut` | 首屏有生命感 |
| 印章旋转 | 仅文字环，26s/圈 linear，中心静止 | 品牌记忆点 |
| 数字滚动 | 目标值 1.6s `power1.out`，视口 88% 触发一次 | 数据可信感 |
| 跑马灯 | `xPercent:-50` / 24s 无限循环 linear | 市集热闹感 |
| 滚动批量浮现 | `ScrollTrigger.batch`，`start:"top 86%"`，`once:true`，`y:36→0 + autoAlpha`，stagger 0.08 | 分区进入节奏 |
| 装饰视差 | hero 圆形 `y:±50`，scrub 1 | 纵深 |
| 横向画廊 | `min-width:1024` 启用：pin 区块 + `scrub:1` + `ease:"none"`，`end:"+=轨道溢出宽"`；不满足则原生横向滚动 | 一屏看全六界面 |

### 8.2 动效规则

1. 只动画 `transform` 与 `opacity`；不动画 width/height/top/left。
2. 入场统一用 `gsap.from()`：无 JS / 加载失败时内容自然可见（不闪白）。
3. `prefers-reduced-motion: reduce` 时全部动效降级为静态（`gsap.matchMedia` 分支 + CSS 兜底）。
4. 悬停微交互优先用 CSS transition；GSAP 只负责编排与滚动。
5. 每个动效必须能说出一句话存在的理由（层级 / 叙事 / 反馈 / 状态），否则删除。

## 9. 图标与图片

- **UI 图标**：内联 SVG，24px 网格、2px 圆头描边、`currentColor`（搜索 / 心形 / 消息气泡 / 盾牌勾 / 星星 / 旗帜 / 订单袋等）。
- **商品图**：原型阶段用 emoji 平铺在功能浅底上占位；正式版替换为学生实拍图（建议 4:3，统一圆角裁切），占位底色沿用 2.2 的五种浅底以保证下架图缺失时版面不塌。
- **头像**：姓名首字 + 品牌色圆底白字（如「林」），不使用默认人形图标。

---

## 10. 可访问性与品质基线

- 正文对比度 ≥ 4.5:1；灰棕次级文字只用于 ≥12px 说明性内容。
- 全站唯一浅色主题：页脚、数据带等大面积区块同样保持浅色（描边区分层级）。
- 触控目标 ≥ 38×38px；交互元素全部用 `button / a` 实现。
- 装饰性内容（跑马灯、印章、装饰圆）标 `aria-hidden`。
- 动效遵循 8.2 第 3 条的减弱动态降级。

## 11. 设计验收清单（每次改版过一遍）

- [ ] 无暗黑区块、无蓝紫渐变、无紫色调
- [ ] 全站只有汽水橙一个主色；绿色只出现在认证 / 信用场景
- [ ] 页面中不出现长破折号「—」；元信息行中「·」每行最多 1 个
- [ ] 所有 CTA 单行、同一意图同一文案
- [ ] 商品卡四态（默认 / 悬停 / 已售 / 审核中）齐全
- [ ] 圆角规则未混用（卡片 16 / 输入 12 / 按钮全圆）
- [ ] 阴影均为暖棕色调
- [ ] 1440 / 1024 / 768 / 375 四档宽度不破版
- [ ] 关闭 JavaScript 时页面内容仍完整可读
- [ ] 系统开启「减弱动态效果」时无滚动驱动动画
